AuraSense
### Full-Stack Mental Health & Sentiment Monitoring Web Application

AuraSense is a specialized, data-driven web application designed to track user sentiment and identify low self-esteem or early indicators of anxiety and depression in real-time. By combining intuitive user experiences with proven clinical metrics, the system translates daily textual reflections and assessments into actionable mental health insights.

---

##  Key Features

* **Real-Time Sentiment Detection:** Utilizes a pre-trained `TextBlob` natural language processing model to analyze text reflections as users type, establishing live sentiment scoring pipelines.
* **Clinically-Backed Assessments:** Fully integrates standard **PHQ-9** (Patient Health Questionnaire-9) and **GAD-7** (Generalized Anxiety Disorder-7) assessment frameworks.
* **Automated Scoring Logic:** Programmed with precise clinical scoring algorithms (e.g., PHQ-9 scoring from 0–4 for minimal indicators up to 20–27 for severe classification) to accurately categorize user metrics.
* **Dynamic Backend Pipelines:** Designed robust server routes and relational database structures to handle user input processing, historic score tracking, and secure response flows.

---

##  Tech Stack

* **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
* **Backend & NLP:** Node.js, Express, Python (TextBlob Integration)
* **Database & UI Design:** SQL, Figma
